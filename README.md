## ✨ 核心特性

- **双引擎代理架构**：
  - **标准代理模式**：基于本地回环与 DNS 桥接，安全注入环境变量与启动参数，轻量稳定。
  - **专属进程代理模式**：通过 API Hook 底层挂起注入与网络拦截，支持多进程树与动态子进程无缝接管。
- **DNS 防污染与智能分流**：
  - 本地回环按规则分流，敏感域名走上游 SOCKS5h 远端解析，彻底规避 DNS 污染。
  - 非名单域名走本地解析，兼顾访问速度与网络安全。
- **纯净系统零污染**：
  - 无需安装虚拟网卡（TAP/TUN）或内核驱动。
  - 不修改全局系统代理与网络适配器配置，退出即还原。
- **多版本客户端自动适配**：
  - 支持 Microsoft Store 商店版及传统独立安装版客户端路径自动探测与启动。
- **现代化可视化控制台**：
  - 基于 Tauri 2.0 + Vue 3 构建，界面轻量精致，内置实时进程监控、网络连接过滤与健康诊断。

## 🛠️ 架构说明

| 模式  | 运行机制 | 适用场景 | 配置路径 |
| --- | --- | --- | --- |
| **标准代理模式** | 本地 DNS 桥接 + 代理环境变量注入 | 常规使用、轻量转发、低系统占用 | `config.json` |
| **进程代理模式** | API Hook 底层注入 + 进程树递归接管 | 深度应用隔离、复杂子进程环境 | `process/config.json` |

> [!NOTE]
> 切换代理模式时系统将自动保存当前配置并无缝切换，不会强行中断客户端当前未完成的任务。

## 🗺️ 产品蓝图与演进规划 (Roadmap)

ProcWeaver 正在从单一客户端工具演进为**面向现代化 AI 与开发工具的一体化网络治理工作台**，以下核心能力正按计划推进：

### 1. 🌐 订阅节点一键导入（内置轻量出站内核）

- **脱离第三方依赖**：直接支持粘贴导入主流订阅链接（Clash YAML / V2Ray / Shadowsocks / 通用 Base64），支持节点自动解析与更新。
- **全闭环极简体验**：内置微型低占用的出站核心，实现从“订阅拉取 ➔ 节点选择/测速 ➔ 专属进程接管”的一站式原生搞定，用户无需预先安装任何外部代理客户端。

### 2. 🤖 扩充主流 AI 编程与效率工具预设（开箱即用）

- **多客户端预设矩阵**：深度内置 **ChatGPT Desktop**、**Claude (Desktop / Code)**、**Google Antigravity (`agy`)**、**Cursor AI 编辑器**、**VS Code + Copilot** 及 **Windsurf** 等专属预设。
- **智能感知与匹配**：全自动识别目标物理安装路径，预置精准的远端防污染域名池与动态衍生子进程（如 Electron 主控、Node.js MCP 进程、CLI 子进程）递归拦截规则链。

### 3. 🩺 AI 连通率与 IP 纯净度体检

- **可用区与合规诊断**：集成一键“AI 落地体检”模块，实时测试当前出口节点针对 OpenAI、Anthropic、Gemini 等主流 API 与 Web 端点的 HTTP 可达性与首字延迟 (TTFT)。
- **节点风控透明化**：精准展示落地国家/地区标志、网络机房类型及风控欺诈度评分，提前告别“地区不受支持 (Region Not Supported)”或 IP 被封禁的烦恼。

### 4. 🔀 多应用同时代理（多进程树并行接管）

- **多端并行常驻**：突破单客户端接管限制，支持在统一控制台内同时挂载、托管并守护多个客户端。
- **多进程树透视**：在控制台中按应用分类透视流量与子进程心跳，多任务协同工作流畅稳定。

### 5. 🎯 多应用独立代理出口（多进程分流不同代理 IP）

- **差异化网络分流**：支持为不同的客户端配置完全独立、并行的上游代理节点。
- **场景赋能**：例如让 ChatGPT 独占美区原生纯净 IP，让 Claude 客户端绑定亚太/欧洲高带宽低延迟专线，各业务通道互不干扰、互不串流。

### 6. 🧩 自定义应用添加器（万物皆可专属代理）

- **开放式接入**：开放自定义目标程序管理，支持用户直接拖入或选择任意 Windows 可执行文件（`.exe`）。
- **通用 Hook 赋能**：无论本地自研 AI 客户端、特定远程开发终端、沙盒容器工具还是特定应用，均可一键赋予免驱动进程代理与防污染远端解析能力。
